## GitHub Pages 설정

1. GitHub에서 `pubg-service-analysis` 이름의 **Public** 저장소를 생성합니다. (README 자동 생성은 선택 사항)
2. 이 압축파일을 해제한 **안쪽 파일 네 개**(`index.html`, `PUBG_Analysis.pdf`, `.nojekyll`, `README.md`)를 저장소 루트에 업로드합니다. 압축파일 자체를 업로드하는 것이 아닙니다.
3. `Settings > Pages > Build and deployment`에서 `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`를 선택하고 저장합니다.
4. Pages 배포가 완료되면 실제 URL로 접속해 이미지, 그래프, 버튼, PDF 인쇄 기능을 점검합니다.

예상 웹 경로(배포 이후에만 동작): `https://qorrkdwns.github.io/pubg-service-analysis/`

PDF 경로(배포 이후에만 동작): `https://qorrkdwns.github.io/pubg-service-analysis/PUBG_Analysis.pdf`

GitHub Pages는 공개 웹사이트입니다. 공유 전 공개할 수 없는 내용이 없는지 확인해 주세요.
